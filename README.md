# Aurora · 2D 景观意向图一键生成 3D 场景

Aurora 是一个依托 AI 图像分割与深度估算能力的景观设计生产力工具（MVP）。它将 2D 景观意向图一键转化为带专业图层结构的 3D 白模场景，打通从概念方案到 SketchUp / Rhino 深化设计的效率壁垒。

> 本仓库为需求文档《AuroraAI 产品需求（MVP）》的完整前端实现。**语义分割与深度估算由真实 AI 模型在浏览器端实时推理**（transformers.js / ONNX Runtime Web），3D 白模依据真实分割足迹与深度图生成。

## 真实 AI 能力

- **语义分割**：`Xenova/segformer-b0-finetuned-ade-512-512`（SegFormer，ADE20K），逐像素识别天空、树木、草地、水体、建筑、道路等类别，映射为景观专业图层。
- **深度估算**：`Xenova/depth-anything-small-hf`（Depth-Anything），输出场景相对深度图，用于驱动地形起伏与体块高度。
- **运行方式**：模型通过 transformers.js 在浏览器本地推理，ONNX Runtime 的 WASM 已随应用自托管；模型权重首次运行从 Hugging Face 下载并缓存（自动在 `huggingface.co` 与 `hf-mirror.com` 之间回退，兼容国内网络）。
- **优雅降级**：若模型无法加载（离线等），自动回退到内置的程序化分层方案，保证流程可跑通。
- **2D 工作台**：中央画布叠加真实的逐像素分割掩膜，点选即按像素归属选中对应图层。
- **3D 生成**：依据分割足迹逐格挤出「顶面 + 侧墙」体块，高度由类别与真实深度共同决定，水体下凹并呈镜面材质，得到贴合意向图的分层白模场景。

> 首次分析需联网下载约数十 MB 的量化模型（含进度显示），之后走浏览器缓存、可离线复用。

## 视觉体系

- 包豪斯极简白色画板风格
- 全息蓝 `#00D2FF` 主色 + 梦境紫 `#7B61FF` 辅助色（3D 属性标识）
- 轻量化圆角线性设计，弹窗 / 按钮 / 进度条统一风格

## 技术栈

- **React 19 + TypeScript**
- **Vite** 构建
- **transformers.js (@huggingface/transformers)** — 浏览器端 AI 推理（语义分割 + 深度估算）
- **Three.js** 实时 3D 视口（足迹挤出建模、PBR 预览、拾取选择、View Cube）
- **Zustand** 全局状态管理（网格化场景、图层、参数、撤销/重做历史）

## 快速开始

```bash
npm install
npm run dev      # 启动开发服务器 http://localhost:5173
npm run build    # 生产构建

```

## 业务主流程（完整闭环）

```
图片上传 → AI 图层拆分（中转页A）→ 2D 智能色块工作台
        → 3D 模型构建（中转页B）→ 3D 模型编辑与同步工作台
        → 导出 / 同步至设计软件
```

### 页面与能力

1. **图片上传页**
   - 横向扁平上传框，24px 全息蓝呼吸发光光效
   - 点击 / 拖拽上传（JPG / PNG / WEBP，单文件 ≤ 20MB）
   - 3–4 张示例图一键填充
   - `⚡分析场景图层` 按钮：无图灰色禁用并气泡提示「请先上传图片」，有图切换为发光激活态

2. **中转页 A：2D 色块层析进度视口**
   - 全息蓝线性进度条 + 百分比动画，顶部「正在分析场景」
   - 每 3 秒轮播专业建模 Tips

3. **2D 智能色块分类工作台**
   - 左栏：原图缩略图（悬浮重新上传/删除，删除后原地转迷你上传框）、模型生成设置（AI 模型、贴图开关、2K/4K、PBR、三角面/四边面）
   - 中央：AI 语义色块画布，点选图斑定义图层，状态提示 + 灵感生成 + 新增图层
   - 右栏：图层架构管理器（全部/3D/2D 筛选、显隐、名称、2D/3D 属性切换、新增图层弹窗）

4. **中转页 B：3D 模型构建进度视口**
   - 顶部「正在创建你的模型……」+ 进度动画 + 轮播 Tips

5. **3D 模型编辑与同步工作台**
   - 左栏继承缩略图 / 配置，栏底新增 `🚀重新构建 3D 模型`
   - 中央 Three.js 3D 视口：
     - `⚙️显示设置`（网格、表面预览 线框/单色/着色/贴图、PBR 预览、背景，仅影响预览）
     - View Cube 快速切换 顶/前/右/透 视角
     - 鼠标侧浮工具箱：`✂️拆分` / `🔗合并` / `🎨PBR 材质检查器`
     - 底部四组工具链：重算 · 图层快捷 · 批量干预（复制/删除/框选/快照/撤销/重做）· 交付输出（同步至设计软件、下载模型）
   - 右栏：三维组件树（与 2D 图层一一映射，2D 淡蓝 / 3D 梦境紫标签、🔧修改）

## 分支判断与异常拦截（强制约束）

- **空图拦截**：未上传图片禁止分析并气泡提示
- **返回 / Logo 规则**：`返回` 仅退回上一级并保留全部配置；点击 `Aurora Logo` 清空全部内存数据并强制返回上传首页
- **2D+3D 混合合并**：弹出黄色风险警示
- **导出校验失败重试**：开启 PBR 导出但未生成贴图、或无可见组件时校验失败，返回配置面板支持更换格式/参数重试；成功则触发本地文件下载并提示「下载成功」
- **同步成功/失败**：分别弹出「同步成功」/「同步失败，请重新同步」
- **撤销 / 重做**：支持图层操作历史（快捷键 Ctrl+Z / Ctrl+Y）

```
  types.ts                    # 类型定义

    common/                   # Logo、TopBar、Modal、Toasts、表单控件
    pages/                    # 上传页、两个中转页、2D/3D 工作台
    workbench/                # 左栏、2D 画布、图层/组件树、3D 视口与各类编辑弹窗
  styles/pages.css            # 页面级样式
  index.css                   # 设计系统 / 全局样式
```
